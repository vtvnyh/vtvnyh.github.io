网站构建文档

个人博客网页的搭建过程

← 返回关于页面

概述

本博客是一个纯静态前端网站，基于 HTML5 + CSS3 + JavaScript 构建， 部署在 GitHub 上。

技术栈

  • HTML5 — 构建页面结构
  • CSS3 — Flex 布局、渐变、过渡动画、响应式设计
  • JavaScript — 原生 DOM 操作、轮播图逻辑、页面过渡动画
  • GitHub Pages — 免费静态托管

页面功能

导航栏

固定在页面顶部的导航栏包含 5 个链接，分别指向博客的各个板块。 在移动端自动折叠为汉堡菜单，点击展开。

轮播图

首页的轮播图使用 CSS transform: translateX() 实现滑动切换效果。 通过 JavaScript 的 setInterval 实现每 4 秒自动播放， 鼠标悬停时暂停。左右箭头和底部圆点支持手动切换。

卡片网格

内容卡片使用 CSS Grid 布局 (grid-template-columns: repeat(auto-fill, minmax(260px, 1fr)))， 自动适应屏幕宽度。卡片在悬浮时有轻微上浮和阴影效果。

页面过渡动画

所有页面之间的跳转都带有淡入淡出效果，使页面切换更流畅。

设计思路

  • 简洁明了 — 白底灰字，减少视觉干扰，聚焦内容
  • 间距统一 — 使用统一的间距比例，使视觉效果更佳
  • 柔和色彩 — 主色 #4a6cf7，辅以浅灰背景和边框，色彩柔和不刺眼
  • 响应式设计 — 布局自动适配
